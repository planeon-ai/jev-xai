# Limitations

jev-xai does not:

- reveal hidden chain-of-thought
- prove causal mechanisms inside opaque models
- guarantee regulatory compliance
- guarantee fairness
- guarantee that an attribution score represents internal reasoning
- convert black-box models into inherently interpretable models

It provides behavioral evidence, reproducibility, counterfactual evidence, approximate attribution, and stability measurement.

Out of this release: anchors, permutation importance, SHAP, LIME, PDF packs, JavaScript dashboards, distributed execution, OpenTelemetry export, model registries, and framework-specific agent SDKs.
